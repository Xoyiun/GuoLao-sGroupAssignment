## 一、作業規範摘要

1. 輸入必修課、候選選修課、學分限制、不可上課時段及偏好條件後，搜尋所有可行課表，並依自訂評分函式排序。
2. 必要條件：不得衝堂、必修課必須全部納入、總學分須介於上下限之間、不得選擇額滿課程、不得安排在禁止上課時段。
3. 偏好條件：減少每週到校天數、減少空堂、避免早八課程、集中上課時段、提高偏好課程的選課比例。
4. 自行定義評分公式及權重，說明不同權重如何影響推薦結果。

## 三、輸入

`SearchOptimalSchedules(database, studentId, preferences)`，`preferences` 為字典：

| 欄位 | 型別 | 預設 | 說明 |
| :--- | :--- | :--- | :--- |
| `required_courses` | 字串清單 | `[]` | 必修課，全部都要排入 |
| `candidate_courses` | 字串清單 | `[]` | 候選選修課，可選可不選 |
| `min_credits`、`max_credits` | 整數 | 9、學生學分上限 | 方案中新排入課程的總學分範圍 |
| `blocked_slots` | 時段清單 | `[]` | 不可上課的時段 |
| `preferred_courses` | 字串清單 | `[]` | 偏好課程（新增） |
| `weights` | 字典 | 見第五節 | 各項偏好的權重，只需填要調整的項目（新增） |

## 四、偏好指標

每個方案以「學生已選課程＋方案中的課程」合起來的一週課表計算，因為到校天數與空堂是看整週。

| 指標 | 欄位 | 計算方式 | 對應偏好 |
| :--- | :--- | :--- | :--- |
| 總學分 | `credits` | 方案中新排入課程的學分總和 | （基本分） |
| 到校天數 | `campus_days` | 有課的星期數（活動日期換算成星期） | 減少每週到校天數 |
| 空堂數 | `gap_periods` | 每天第一節課到最後一節課之間沒課的節數總和 | 減少空堂 |
| 早八節數 | `early_periods` | 第 1 節有課的天數 | 避免早八 |
| 半天區段數 | `half_day_blocks` | 有課的「半天」數；一天分上午（1–4 節）、下午（5–9 節）、晚上（a–c 節） | 集中上課時段 |
| 偏好比例 | `preferred_ratio` | 方案中的偏好課程數 ÷ 偏好課程總數；沒有指定偏好課程時為 0 | 提高偏好課程比例 |

## 五、評分公式與權重

```text
score = 1.0 × 總學分
      − 2.0 × 到校天數
      − 1.0 × 空堂數
      − 1.5 × 早八節數
      − 0.5 × 半天區段數
      + 5.0 × 偏好比例
```

分數取到小數第 2 位，由高到低排序；分數相同時依課程代號排序，確保結果固定。

| 權重 | 欄位 | 預設 | 理由 |
| :--- | :--- | ---: | :--- |
| 學分 | `credits` | 1.0 | 以 1 學分 = 1 分作為基準 |
| 到校天數 | `campus_days` | 2.0 | 多到校一天的成本，約等於少修 2 學分 |
| 空堂 | `gap_periods` | 1.0 | 一節空堂相當於少 1 學分 |
| 早八 | `early_periods` | 1.5 | 比一般空堂更不受歡迎 |
| 集中 | `half_day_blocks` | 0.5 | 輔助指標，避免蓋過到校天數 |
| 偏好比例 | `preferred_ratio` | 5.0 | 全部偏好課都排到時，可抵消多到校 2.5 天 |

權重必須是大於或等於 0 的數字；填 0 代表不在意該項。填了不存在的權重名稱或負數，回報 `INVALID_FIELD`。

### 權重如何影響推薦結果

以測試 `test_WeightsChangeRanking` 的兩個方案為例（各 3 學分）：

| 方案 | 時段 | 到校天數 | 早八 | 預設權重分數 | 早八權重 = 0 時分數 |
| :--- | :--- | ---: | ---: | ---: | ---: |
| EARLY | 星期一第 1–2 節 | 1 | 1 | −1.0 | 0.5 |
| LATE | 星期一第 5–6 節 | 1 | 0 | 0.5 | 0.5 |

* 預設權重：避免早八，LATE 排第一。
* 把早八權重設為 0：兩個方案同分，改依課程代號排序，EARLY 排第一。
* 同理，把學分權重調高會偏向修滿學分的方案；把到校天數權重調高會偏向集中在少數幾天的方案。

## 六、輸出

```text
(True, OK, [
  {"courses": [...], "total_credits": 9, "score": 1.5,
   "metrics": {"credits": 9, "campus_days": 2, "gap_periods": 0, "early_periods": 1,
               "half_day_blocks": 3, "preferred_ratio": 0.5}},
  ...
])
```

| 情況 | 回傳 |
| :--- | :--- |
| 有可行方案 | `(True, OK, 方案清單)`，依分數由高到低 |
| 沒有可行方案 | `(False, NO_FEASIBLE_SCHEDULE, [])` |
| 學生不存在、必修課不存在、欄位或權重格式錯誤 | `(False, INVALID_FIELD, [])` |
