## 一、模組概述

`F1_DataManager.py` 提供課程、學生與教室資料的查找、驗證、新增、修改、刪除及查詢功能。核心函式以記憶體中的 `db` 字典作為資料來源，不負責檔案讀寫；`F1Manager` 則繼承 `F6_StorageManager.py` 中的 `DataManager`，將操作與自動存檔串接。

一般操作函式成功時回傳 `(True, "OK")`，失敗時回傳 `(False, 錯誤碼)`。查詢函式回傳符合條件的資料清單；單筆查找函式在找不到資料時回傳 `None`。

## 二、資料介面

資料庫物件 `db` 是包含資料清單的字典：

```python
db = {
    "classrooms": [...],
    "courses": [...],
    "students": [...],
    "activities": [...],
}
```

刪除教室時會檢查 `activities` 中是否有活動使用該教室。課程、學生及教室的主要欄位如下：

| 資料類型 | 欄位 |
|---|---|
| 教室 | `classroom_id`、`capacity`、`equipment`；可選 `building_id`、`building_name` |
| 課程 | `course_id`、`title`、`credits`、`required`、`teacher`、`classroom_id`、`capacity`、`time_slots`；另使用 `enrolled_count` |
| 學生 | `student_id`、`name`、`department`、`max_credits`、`enrolled_courses` |

課程時段 `time_slots` 為非空清單，元素格式為 `{"day": 星期, "period": 節次}`。星期範圍為 1–7，節次可為 `"1"`–`"9"`、`"a"`、`"b"` 或 `"c"`。

## 三、公開函式接口

### 3.1 查找及計算

| 函式 | 說明 | 回傳值 |
|---|---|---|
| `find_course(db, course_id)` | 依課程代號查找課程 | 課程字典或 `None` |
| `find_student(db, student_id)` | 依學號查找學生 | 學生字典或 `None` |
| `find_classroom(db, classroom_id)` | 依教室代號查找教室 | 教室字典或 `None` |
| `count_enrolled(db, course_id)` | 根據學生的 `enrolled_courses` 計算修課人數 | 整數 |
| `remaining_seats(course)` | 以 `capacity - enrolled_count` 計算剩餘名額；未提供 `enrolled_count` 時以 0 計 | 整數 |

### 3.2 資料驗證

| 函式 | 說明 | 回傳值 |
|---|---|---|
| `validate_time_slots(time_slots)` | 驗證時段清單、星期與節次格式，以及時段是否重複 | `(ok, code)` |
| `validate_course_fields(db, course)` | 驗證課程必要欄位、學分、容量、指定教室、教室容量及時段 | `(ok, code)` |
| `validate_student_fields(db, student)` | 驗證學生必要欄位、學分上限、已選課程清單及課程存在性 | `(ok, code)` |

以上驗證函式不負責檢查課程代號或學號是否重複；該檢查由新增函式處理。

### 3.3 教室操作

| 函式 | 說明 | 回傳值 |
|---|---|---|
| `add_classroom(db, room)` | 驗證並新增教室。`equipment` 須為文字清單，未提供時為空清單；建築欄位預設為空字串 | `(ok, code)` |
| `delete_classroom(db, classroom_id)` | 刪除教室；教室不存在或仍被課程／活動使用時回報錯誤 | `(ok, code)` |

### 3.4 課程操作

| 函式 | 說明 | 回傳值 |
|---|---|---|
| `add_course(db, course)` | 驗證並新增課程；成功新增時 `enrolled_count` 設為 0 | `(ok, code)` |
| `update_course(db, course_id, changes)` | 修改允許欄位；`course_id` 不可修改，容量不可低於目前修課人數 | `(ok, code)` |
| `delete_course(db, course_id)` | 刪除課程；若有學生選修或 `enrolled_count` 大於 0 則拒絕 | `(ok, code)` |
| `query_courses(db, course_id=None, teacher=None, day=None, required=None, has_seats=None)` | 依課程代號、教師、星期、必修狀態及是否尚有名額篩選。多條件採 AND；`None` 表示不套用該條件 | 課程清單 |

課程可修改欄位：`title`、`credits`、`required`、`teacher`、`classroom_id`、`capacity`、`time_slots`。

### 3.5 學生操作

| 函式 | 說明 | 回傳值 |
|---|---|---|
| `add_student(db, student)` | 驗證並新增學生；未提供 `enrolled_courses` 時預設為空清單 | `(ok, code)` |
| `update_student(db, student_id, changes)` | 修改學生姓名、系所或學分上限；不允許透過此函式修改選課清單 | `(ok, code)` |
| `delete_student(db, student_id)` | 刪除學生，並將其已選課程的 `enrolled_count` 各減 1（最低為 0） | `(ok, code)` |
| `query_students(db, student_id=None, department=None, course_id=None)` | 依學號、系所或已選課程篩選；多條件採 AND，`None` 表示不套用該條件 | 學生清單 |

## 四、`F1Manager` 類別接口

`F1Manager` 繼承自 `F6_StorageManager.py` 的 `DataManager`，使用 `self.data` 作為上述純函式的 `db` 參數。以下方法提供相同的教室、課程及學生操作，不需呼叫端自行傳入 `db`：

```text
add_classroom(room)
delete_classroom(classroom_id)
add_course(course)
update_course(course_id, changes)
delete_course(course_id)
query_courses(**conditions)
add_student(student)
update_student(student_id, changes)
delete_student(student_id)
query_students(**conditions)
```

新增、修改及刪除方法在業務操作成功後會呼叫自動存檔。若存檔失敗，回傳 `(False, "SAVE_FAILED")`；業務操作本身失敗時不執行存檔。查詢方法不會存檔。`_commit(result)` 是類別內部使用的方法，不屬於一般呼叫端接口。

## 五、常用錯誤碼

| 錯誤碼 | 意義 |
|---|---|
| `OK` | 操作成功 |
| `NOT_FOUND` | 找不到要修改或刪除的資料 |
| `DUPLICATE_ID` | 課程、學生或教室代號重複 |
| `INVALID_FIELD` | 欄位缺漏、格式錯誤（含教室設備不是文字清單）或修改了不允許的欄位 |
| `INVALID_CREDITS` | 學分或學生學分上限不符合規定 |
| `INVALID_CAPACITY` | 容量無效，或修改後低於目前修課人數 |
| `INVALID_TIME_SLOTS`、`INVALID_DAY`、`INVALID_PERIOD`、`DUPLICATE_SLOT` | 時段清單、星期、節次或重複時段錯誤 |
| `CLASSROOM_NOT_FOUND`、`CAPACITY_EXCEEDS_ROOM`、`CLASSROOM_IN_USE` | 指定教室不存在、課程容量超過教室容量，或教室仍在使用 |
| `COURSE_NOT_FOUND`、`COURSE_HAS_STUDENTS`、`INVALID_STUDENT_COURSES` | 學生所選課程不存在、課程仍有學生，或選課清單含重複課程 |
| `SAVE_FAILED` | `F1Manager` 自動存檔失敗 |

## 六、使用示例

```python
ok, code = manager.add_course({
    "course_id": "CS101",
    "title": "程式設計",
    "credits": 3,
    "required": True,
    "teacher": "王老師",
    "classroom_id": "R101",
    "capacity": 40,
    "time_slots": [{"day": 1, "period": "1"}],
})

if ok:
    courses = manager.query_courses(teacher="王老師", has_seats=True)
else:
    print(f"新增失敗：{code}")
```

使用純函式時，呼叫端需自行傳入正確結構的 `db`，且操作會直接修改其中的清單與字典；使用 `F1Manager` 時則由類別管理資料並在成功的變更操作後嘗試存檔。
